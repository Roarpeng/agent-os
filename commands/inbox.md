argument-hint: [日期，留空则取最新一期]

读取 `docs/inbox/` 下最新的 digest 文件（或指定日期：$ARGUMENTS），执行经验沉淀流程：

1. **汇总**：≤10 行说清本期新内容（来源、主题、数量）。若 digest 末尾已有"候选洞察"段落，以它为输入。
2. **提炼**：最多 3 条值得沉淀的经验。每条说明——洞察、来源、为什么值得、建议升级到哪一层（AGENTS.md / command / skill / 仅记录到 docs）。
3. **门槛**：与 Agent OS 现有原则重复的、只出现过一次未见长期价值的、纯新闻性的——标记"不沉淀"并给一句理由。
4. **确认后执行**：先列出全部建议，等我确认，再修改对应文件，并更新 `docs/changelog.md`。

原则：宁缺毋滥。规则和技能"只减不增"是常态；新增一条规则的成本是之后每次会话都为它付 Token。
