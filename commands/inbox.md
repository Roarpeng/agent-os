---
description: 灵感收件箱——对照系统现状过滤 digest，提炼候选经验，人工确认后沉淀并登记
argument-hint: [日期，留空则取最新一期]
---

读取 `docs/inbox/` 最新 digest（或指定日期：$ARGUMENTS），执行"过滤 → 提炼 → 确认 → 登记"：

1. **加载系统现状**（过滤依据）：读 `AGENTS.md`、`commands/*.md`、`skills/*/SKILL.md`、`agents/*.md`、`pipeline/absorbed.json`。
2. **过滤已接入内容**：与上述任何一项等价或高度重叠的条目，归入"已覆盖"小节并注明被哪一项覆盖——判断对象是想法，不是链接（同一想法换出处也算已覆盖）。这些不再进入提炼。
3. **汇总**：≤10 行说清本期新内容。若 digest 末尾已有"候选洞察"段落，以它为初筛输入，但过滤判断以你自己读取的系统现状为准。
4. **提炼**：最多 3 条值得沉淀的经验——洞察、来源、为什么值得、建议升级到哪一层（AGENTS.md / command / skill / 仅记录）。
5. **门槛**：只出现过一次未见长期价值的、纯新闻性的——标记"不沉淀"并给一句理由。宁缺毋滥，规则和技能"只减不增"是常态。
6. **确认后执行**：列出全部建议等我确认；确认后修改对应文件、更新 `docs/changelog.md`，并把每条被吸收的洞察登记进 `pipeline/absorbed.json`（字段：date / insight / source / into）——这是下次自动过滤的依据。最后 commit + push 到远端。
