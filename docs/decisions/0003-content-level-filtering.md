# ADR-0003：内容级过滤——已接入的想法不再重复打扰

- 日期：2026-10-02
- 状态：已采纳

## 背景

digest 去重只到"链接/ID 级"（`state.json`）：同一篇文章不会重复出现，但**同一个想法换了出处**（新文章、访谈、他人转述）会再次进入候选，用户要反复处理已沉淀过的内容。

## 决策

1. **过滤依据是"系统现状"，运行时动态生成**（`distill.build_manifest`）：AGENTS.md 全文 + 命令/技能/子代理的 description + `absorbed.json` 最近 30 条已吸收洞察。动态生成意味着新增规则/技能后过滤自动跟上，不维护关键词表、零额外维护面。
2. **LLM 做等价性判断**：与清单等价或高度重叠的想法归入"已覆盖（过滤）"小节，注明被哪一项覆盖——**透明可审计，不静默丢弃**。判断对象是想法，不是链接。
3. **吸收闭环**：`/inbox` 确认沉淀后写入 `absorbed.json`（date / insight / source / into），下次过滤自动生效。
4. **零密钥兜底**：未配 LLM_API_KEY 时云端跳过提炼，同样的过滤判断由本地 `/inbox` 用会话模型完成。

## 后果

+ 同一想法跨出处重复出现会被识别并过滤；用户只看到真正的新东西。
+ 清单跟随系统自动演进；过滤结果保留在 digest 中供人抽查。
- 等价性判断依赖 LLM，存在误判可能——因此"已覆盖"条目可见可查，发现误判时把该条目手动加入候选即可。
